# Aka delay routines

`aka-jp-rev0` is the Japanese origin reference. All 7 cataloged releases (Japanese, German, English, Spanish, French, Italian) independently contain one ROM0 `DelayFrame` and one `DelayFrames` caller bound to it. The reports retain release identity, addresses, HRAM flag location and function hashes without publishing ROM bytes. Existing candidate/verified status is preserved and is not promoted by this match.
