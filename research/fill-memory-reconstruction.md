# Aka `FillMemory` disassembly

The Japanese release `aka-jp-rev0` is the origin reference. All 7 cataloged releases (Japanese, German, English, Spanish, French, Italian) contain exactly one ROM0 `classic` implementation. The RGBDS source preserves the observed countdown strategy and the release maps retain identity, address, variant and code hash without publishing ROM bytes. Candidate/verified status is carried through from the existing release catalog and is not promoted by this match.
