# PocketMonsters-Aka-Disassembly

Clean-baseline disassembly and reverse-engineering project. Earlier commits remain historical reference; old working-tree layouts and imported conventions are not restored automatically.

Core rules: verify exact target identity/provenance; reconstruct from observed architecture rather than forcing another game's layout; separate observation from hypothesis; prefer reproducible tooling/manifests; preserve meaningful original addresses/labels/IDs; deduplicate only by byte/hash evidence; never commit complete ROM images; keep one live structure and use Git history for history.
